# ☕ CUP2EAT – Eat Your Drink!

Luxury D2C e-commerce storefront and Owner Admin Suite built for **CUP2EAT**, India's edible biscuit coffee cup brand. Engineered as a zero-recurring-cost, high-converting web experience.

## ✨ Key Features

- **Boutique D2C Storefront:** Warm espresso, cream, and gold aesthetic showcasing *Dark Belgian Chocolate*, *Madagascar Vanilla*, *Royal Elaichi Chai*, and *Signature Assorted* edible cup boxes.
- **Pack Size & Variant Selector:** Instant pricing updates across 12, 24, and 50-cup boxes with real-time stock visibility.
- **Customer OTP Authentication:** Frictionless 4-digit Phone/Email OTP login modal with persistent session state.
- **Slide-Over Cart & Checkout:** Promo code validation (`CUP10`), simulated Razorpay/UPI/Card payment flow, and instant order confirmation.
- **Automated GST Tax Invoice:** One-click printable GST invoice generation with itemized tax breakdown.
- **Live 4-Step Order Tracking:** Real-time order status tracker (*Confirmed → Freshly Baked → Dispatched → Delivered*).
- **Owner Admin Dashboard:** Built-in management panel to monitor revenue, update live order statuses, adjust box inventory, and launch new flavours.
- **WhatsApp Concierge:** Floating direct-to-WhatsApp customer support integration.

## 🚀 Tech Stack

- **Frontend:** Semantic HTML5, Tailwind CSS, Vanilla JavaScript (ES6+)
- **Typography:** Playfair Display & Plus Jakarta Sans
- **Deployment:** Static zero-server architecture (Vercel / Netlify ready)
